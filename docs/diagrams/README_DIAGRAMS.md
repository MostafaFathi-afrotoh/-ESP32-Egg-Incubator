# Engineering diagrams — ESP32 Egg Incubator v2.0

SVG set for documentation, academic reports, and assembly.

| File | Content |
|------|---------|
| `01_system_block_diagram.svg` | System blocks: sensors, ESP32, actuators, cloud, NVS, safety |
| `02_circuit_schematic.svg` | Logical schematic + GPIO summary |
| `03_wiring_diagram.svg` | Bench wiring + color codes + safety checklist |
| `04_pcb_layout_guide.svg` | Placement / layout rules (not Gerbers) |
| `05_enclosure_design.svg` | Front/top enclosure concept |
| `06_bom.svg` | Bill of materials table |
| `07_testing_guide.svg` | Hardware/firmware test matrix |

## Usage

- Open in browser, Inkscape, Illustrator, or VS Code SVG preview.
- Print at 100% on A4; scale if needed.
- Pin numbers match `Memory10_2.ino` firmware.

## Disclaimer

These are **documentation drawings**, not certified manufacturing or electrical safety certificates. Mains wiring must follow local regulations and qualified practice.
