ESP32 Egg Incubator Controller v2.0.1
=====================================

Requirements
------------
- Arduino IDE 2.x (or 1.8+) with ESP32 board package
- Board: ESP32 Dev Module (or compatible)

Libraries (Library Manager)
---------------------------
- DHT sensor library (Adafruit)
- Adafruit Unified Sensor
- OneWire
- DallasTemperature
- LiquidCrystal I2C
- UniversalTelegramBot (optional, for Telegram)
- ArduinoJson (dependency of UniversalTelegramBot)

Setup
-----
1. Copy secrets.h.example → secrets.h and fill WiFi / Telegram / Adafruit values.
2. Open the folder ESP32-Egg-Incubator in Arduino IDE
   (or open ESP32_Incubator.ino; the sketch folder name should match the .ino name).
3. Select board: ESP32 Dev Module, correct COM port.
4. Upload.
5. Serial Monitor at 115200 baud. Type HELP for commands.

Important
---------
- Do NOT commit secrets.h (it is listed in .gitignore).
- Control and safety run offline; WiFi is optional.
- Keep EMAIL-related features disabled unless you have tested SMTP with the Watchdog.
